# B 模块：答题行为与时间 —— 初步发现（第一轮）

## 数据口径
- 输入：A 模块去重后日志 `records_deduplicated.csv`，共 231,812 条有效提交。
- 时间：原始 `time` 为 Unix 秒级时间戳（UTC），展示时转换为北京时间（UTC+8）。
- 时间范围：2023-08-31 16:46 至 2024-01-25 12:58（北京时间）。
- 时间质量：无法转数字 0 条、含小数秒 0 条、非正时间戳 0 条、超范围 0 条。
- 活跃天数 = 有有效提交的不同日期数；单题尝试次数按“学生 + 题目”组合统计；真实多次提交不删除。
- 两次提交间隔不等于真实答题耗时；程序运行耗时（timeconsume）不等于学生学习时间；未观察到提交不能解释为未学习。

## 发现一：重试是普遍行为，但分布高度不均
50,483 个“学生-题目”对中，**70.77% 存在多次提交**；单题尝试次数中位数为 3 次，平均 4.59 次，最多达 152 次。
说明多数学生面对同一题会反复提交调试，但少数组合的极端重试拉高了均值，重试行为呈长尾分布。
（对应图：活跃天数分布图 / 单题尝试次数分布；对应表：question_attempt_summary.csv）

## 发现二：学习活跃天数分化明显
1,365 名有提交的学生中，活跃天数中位数 24 天，25% 分位仅 15 天，而 75% 分位达 62 天，最长 80 天，最短 1 天。
说明学生参与节奏差异很大：一部分学生集中在少数几天突击提交，另一部分持续多日活跃。
**注意**：活跃天数只反映“有提交的日期”，不能等同于每天学习；未观察到提交的日子不能解释为未学习。
