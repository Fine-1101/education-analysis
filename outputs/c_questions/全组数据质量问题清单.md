## 已统一的全组口径
- 学生编号、题目编号按文本处理，编号格式不做数字化改写。
- 重复判定使用九字段：class、student_ID、title_ID、time、state、score、method、memory、timeconsume，共排除 1006 行，A 与 C 结果一致。
- 时间为 Unix 秒 UTC 时间戳，全组统一按东八区（+8 小时）解释。
- 正确 = state 为 Absolutely_Correct；Partially_Correct 计部分分不计正确；Error 系列计错误。
  官方说明给出 state 共 12 种情况，数据中合法取值恰为 12 种，该枚举集合已获官方数量校验。
- 得分率分母为该题满分；正确率分母默认学生×题目组合数，提交次数口径另行给出。
- 原始数据文件一律不修改，被排除记录全部单独留档；官方说明文档另存 data/docs/，不并入原始数据。
- 未作答不记零分，不进入分母。
