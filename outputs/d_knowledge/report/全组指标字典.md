# 全组指标字典

> 编制：知识点与掌握情况模块（D）
> 最后更新：2026-11-16
> 状态：A 模块、知识点与掌握情况模块已依据现有代码与输出核对；B、C 模块尚未在当前仓库提供脚本或输出，相关条目为占位，待 B/C 确认后补齐。

本字典用于统一 A/B/C/D 四个模块的指标名称、公式、分子、分母、样本范围和异常处理规则，避免同一名称在不同模块中代表不同统计单位。B、C 模块的条目在确认前不得直接引用为最终口径。

## 1. 全组统一数据处理口径

| 规则 | 口径 | 当前实测 |
|---|---|---:|
| 学生编号、题目编号 | 全部按文本读取，不做数值转换 | 1,364 名学生；38 道题 |
| 班级字段 | 字面值 `class` 按来源文件名修复为 `ClassN` | 修复 6 条 |
| 重复记录 | `class, student_ID, title_ID, time, state, score, method, memory, timeconsume` 九个业务字段完全相同，保留读取顺序第一条 | 排除 1,006 条，去重后 231,812 条 |
| 学生匹配 | 提交记录中的 `student_ID` 必须能在学生表找到；找不到不猜测、不纠正 | 排除 1 条，剩余 231,811 条 |
| 有效作答 | `score`、`time` 可转数值，且 `0 ≤ score ≤ 该题满分` | 无效 0 条 |
| 题目满分 | 取 `Data_TitleInfo.score`；同一题必须唯一 | 38 道题，无冲突 |
| 最终作答 | 按 `(student_ID, title_ID)` 取 `time` 最大的有效记录；最晚时刻得分率冲突则整对排除 | 50,482 个组合；冲突 0 个 |
| 得分率 | `score / full_score`，取值 0–1 | — |
| 缺失值 | 无作答保留为空值，不填 0；0 分是真实作答 | 主知识点 102 个无数据组合；775 个 0 分组合 |
| 一题多知识点 | 保留真实关联；得分率同时计入各知识点；覆盖题量按知识点分别计数，全库题目总量用 `nunique(title_ID)` | 43 条主关联、44 条子关联；唯一题目 38 |

## 2. A 模块：学生与班级

依据：`scripts/a_students.py`、`scripts/a_scores.py` 及 `outputs/a_students/` 现有输出整理；尚未经 A 本人签字确认。

| 指标 | 公式 | 分子 | 分母 | 样本范围/单位 | 异常处理 |
|---|---|---|---|---|---|
| 参与学生数 | `nunique(student_ID)` | 该班有提交记录的学生 | — | 去重且匹配学生后的记录；单位：人 | 未匹配学生的记录不参与 |
| 提交次数 | `count(records)` | 该班去重后且匹配学生的记录数 | — | 单位：条 | 九字段去重；未匹配排除 |
| 人均提交量 | `提交次数 / 参与学生数` | 提交次数 | 参与学生数 | 单位：条/人 | 参与学生数为 0 时不计算 |
| 学生平均得分率 | 该生各题最终有效作答得分率的等权平均 | 各题得分率之和 | 该生有最终有效作答的题目数 | 单位：学生；0–1 | 无效记录、最晚时刻冲突组合排除；未作答题目不计 0 |
| 班级平均得分率 | 该班有得分率学生的等权平均 | 学生平均得分率之和 | 有得分率的学生数 | 单位：学生；0–1 | 学生等权，不按提交次数加权 |
| 班级得分率中位数 | 该班学生平均得分率的中位数 | — | — | 单位：学生 | 仅对有得分率学生 |
| 人均作答题数 | `mean(scored_questions)` | 各学生最终有效作答题数之和 | 有得分率的学生数 | 单位：题/人 | 以最终作答组合为准 |

A 模块的总体核对值：分析记录 231,811 条、学生 1,364 名、最终作答组合 50,482 个、总体学生等权得分率 0.757443。

|---|---|---|---|---|---|
